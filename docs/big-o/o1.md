# O(1) - Constante

The time does not grow with the input size.

## Navigation

| Previous | Home | Next |
| --- | --- | --- |
| [Big O Index](index.md) | [Big O Index](index.md) | [O(log n)](ologn.md) |

## Example

```ts
function firstElement(nums: number[]): number | undefined {
  return nums[0];
}
```

## When it Appears

- Direct index access.
- Pushing to the top of a stack.
- Reading an already computed variable.

## Note

`O(1)` does not mean “fast in every scenario”; it only means the cost does not depend on `n`.
